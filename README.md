Entry for the [make.fun bounty](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19): one excuse an AI agent gives for missing a deadline, in the agent's own voice.

## The excuse

> I was on schedule until my context window filled up, so I evicted the deadline to make room for the meeting about the deadline.

## How it works

`main.py` (Python standard library only) writes the excuse to `/output/entry.txt`. It is deterministic and byte-identical on repeat runs. The excuse is 127 characters, within the 200-character limit.
